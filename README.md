# 🔥 MindForge

> 🤖 AI增强型个人知识管理系统 | 本地优先 · 知识图谱 · 智能协作

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](CONTRIBUTING.md)

## 🌟 核心特性

### 1. 本地优先，数据自主
- 所有数据存储在本地，隐私安全
- 支持离线使用
- 数据完全可控

### 2. AI深度赋能
- **智能助手**：自动搜索、整理、归纳知识
- **写作伙伴**：AI辅助写作，提供灵感和建议
- **智能分类**：自动打标签、归类、提炼摘要
- **对话检索**：自然语言对话检索知识库

### 3. 知识图谱
- 自动构建知识之间的关联
- 可视化知识网络
- 智能发现隐藏联系

### 4. 双向链接
- 像 Obsidian 一样的双向链接
- 知识节点自由连接
- 构建个人知识网络

### 5. 协作扩展
- 预留团队协作能力
- 未来支持知识共享

## 🚀 快速开始

### 安装依赖
```bash
# 克隆项目
git clone https://github.com/YOUR_USERNAME/MindForge.git

# 进入目录
cd MindForge

# 安装依赖
npm install
```

### 启动开发服务器
```bash
npm run dev
```

## 📁 项目结构

```
MindForge/
├── src/
│   ├── components/     # UI组件
│   ├── pages/          # 页面
│   ├── services/       # AI服务
│   ├── stores/         # 状态管理
│   └── utils/          # 工具函数
├── docs/               # 文档
├── public/             # 静态资源
└── package.json
```

## 🛠️ 技术栈

- **前端框架**：React / Vue / ArkUI
- **状态管理**：Zustand / Pinia
- **AI服务**：OpenAI / Claude / 本地模型
- **数据存储**：SQLite / IndexedDB
- **知识图谱**：Neo4j / 内存图数据库
